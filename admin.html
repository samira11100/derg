Bağlantı

Bu sayfa değişiklikleri doğrudan GitHub'daki derg deposuna kaydeder. Bunun için kendi GitHub hesabından, sadece bu depoya erişebilen bir erişim anahtarı (token) oluşturman gerekiyor — anahtar yalnızca bu tarayıcıda saklanır, başka hiçbir yere gönderilmez.

Token nasıl oluşturulur?

GitHub → sağ üstteki profil fotoğrafı → Settings → sol menüde en altta Developer settings → Fine-grained tokens → Generate new token. "Repository access" kısmında sadece derg deposunu seç, "Permissions" kısmında Contents için "Read and write" ver. Oluşan anahtarı kopyalayıp aşağıya yapıştır.
